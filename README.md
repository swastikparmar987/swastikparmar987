## About

I'm an AI/ML student interested in the engineering behind reliable, real-world systems. My work spans computer vision, sequence modelling, LLM evaluation, and full-stack applications that put models in front of people.

- **Currently interested in:** computer vision, model reliability, and practical AI safety.
- **How I work:** build a baseline, measure it, investigate failure cases, and iterate.
- **Outside the model:** APIs, deployment, tooling, and product experience matter too.
